# Landing Page – Restaurante Bom Sabor

## Sobre o projeto

Landing page desenvolvida para o cliente consultar as opções do cardápio e fazer o pedido ao ir para o WhatsApp do Restaurante.

## Tecnologias utilizadas

- **HTML5**
- **CSS3** (Flexbox e Grid Layout)

## Funcionalidades e boas práticas

- **Mobile First:** pensado primeiro para telas pequenas e ampliado para telas maiores.
- **Design responsivo:** adaptável a diferentes tamanhos de tela.
- **HTML semântico:** uso de tags que descrevem o significado do conteúdo, ótimo para acessibilidade e SEO.
